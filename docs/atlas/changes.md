# What changed

## 2026-11-03

- The real place prototype can now be played by two people at once (`?proto=place&coop=1`). The oldest tab in the room acts as the referee: when you drop a log at a station, it decides whether that log counts, so two people can't both drop the last one. Once a second it sends everyone the whole railway, like a scorekeeper reading the scoreboard aloud. New story: [two of you build one railway](#story/coop).
- The server learned to keep playtest notes: a prototype page can send what happened in a session, and the team reads it back later, like a flight recorder. Nothing a player sees changed.
- Everything else was only in your own tab: the place prototype got sea and gull sounds, little guys who walk and chatter, decks you can sit on, and crystals; touch players can sprint by pushing the stick far; the soapbox left the island. Nothing else in the picture moved.
- Later the same day: those playtest notes now actually get written. Any prototype page quietly sends a diary of the session to the server (where you walked, what you pressed, where you got stuck, how smooth it ran), unless you add `&notrack=1`, and the team reads it back with a heat map, like a coach watching game tape. It travels straight to the server, not to other players, so no arrow in the picture moved.
- Later still, only small fixes landed: the server guards that playtest diary better, limiting how many sessions one visitor can send in an hour and keeping real play sessions longest, like a guestbook that throws out spam before signatures. Nothing in the picture moved.
- Last of the day: the place prototype grew a whole job (chop by hand, then a better axe, a cart, a second line over the sea, trains that come when you call), and the two-player version now sends those new pieces through the same referee and the same once-a-second scoreboard, so [two of you build one railway](#story/coop) still tells it right. A new water prototype (`?proto=water`) paints waves and shoreline foam only in your own tab, like a painted backdrop, and the rest was tools for agents to watch and measure the game. Nothing in the picture moved.
- Overnight: two-player place got fairer about leaving. A great beam or boiler on your shoulder now shows in your presence, so if you walk out carrying one, your partner's tab puts it back where it was found, like returning a library book for someone who left town. A log you dropped is only given back if the referee says no or actually leaves, never just because the answer was slow. The cart also carries rails now. See the new last step of [two of you build one railway](#story/coop).
- Also new, only in your own tab: a sky prototype (`?proto=sky`) with richer daylight and soft drifting clouds, plus more tools for agents. Nothing else in the picture moved.

## 2026-11-02

- Last of the day: a new player's first visit, riding a cart off a rail and smashing through the BOOGLE title in mid-air, graduated from a prototype into the game and got its own folder. It only plays in your own tab, like a welcome film shown to each guest alone, so nothing shared changed and no arrow in the picture moved.
- Later the same day, only controls: the hotbar is gone, so you hold one thing at a time, and picking something up tosses what you had a step ahead, like having just two hands. The ball no longer rides on your back; it sits in your hand while you own it. The main button no longer bumps a nearby ball. Nothing shared changed, so nothing in the picture moved.
- Our server now hosts every room. Tabs used to find each other through the server and then talk directly; now each tab keeps one line open to the server, which passes things along and keeps the island itself, like a board-game café that keeps the board set up between visits. [You join a room](#story/join) is rewritten to match.
- The shared world now lives on the server. When you plant a mushroom, the edit goes up to the server, gets its tick there, and comes back down to every tab. The island keeps ticking, and saves every couple of seconds, even with nobody online.
- The Boogler still runs in one player's tab, but now [the server picks that tab](#story/boogler) and picks a new one if it leaves.
- New story: [opening day starts](#story/opening). One stamped tick starts a whole scripted moment (the gathering call, the bell, the era change), so every tab and every late joiner sees the same thing without anything else being sent.
- Two new folders get notes: prototypes (everything behind `?proto=`) and shared HUD pieces.
- Later the same day, only small fixes landed: the code now double-checks every list lookup before trusting it, like checking a drawer isn't empty before reaching in. Nothing in the picture moved.
- Later still: three prototype toys were cut (the wheelbarrow, the ride flatbed and the toppling stack), so two presence keys they used (`barrow`, `seat`) are gone. A new prototype, the long train crossing, is Local only: it shares nothing, so no arrow in the picture changes.
- The checks now guard the borders between parts, like walls between rooms: the shared world and the network code can't reach into drawing or the player, and two files can't lean on each other in a loop.
- Last update of the day: a new prototype, the rail loop (`?proto=net`), where crates ride the train from camps to a growing village. It reuses the shared-world edits that already exist, like a new board game played with the same pieces, so no arrow in the picture changes.
- After that, only small fixes landed: the last two loops between files were untangled (the player and cave code now lean on small helper files instead of on each other), and an old hero prototype was retired. Nothing in the picture moved.
- Late that night, only small changes again: The Boogler can babble as he talks (behind `?proto=babble`, only your tab hears it), the new Buddy body learned to carry, swim and sit, and the physics-step hooks now run in a numbered order instead of whichever signed up first, like a queue with tickets. Nothing in the picture moved.
- Overnight, only Local changes: The Boogler's babble now plays for everyone, every sound runs through one mixing desk with a volume slider in the pause view, and a page that loads during a deploy reloads once instead of getting stuck. Nothing is shared, so nothing in the picture moved.
- After that, the beach ball and the pings became "entities": each one is a self-contained object that knows how to update, draw and clean up after itself, like a toy that comes in its own box with its own instructions. The ball moved to its own folder; [kicking the ball](#story/ball) still travels the same way. Everyone's avatar is now the Buddy. Nothing shared changed shape, so no arrow in the picture moved.
- Then only small fixes: each page now carries its build name in a label on the page itself, not baked into the code files, so a deploy that changes nothing else no longer makes returning players download the same code again. A new entity also gets its "alive" flag and id filled in for it. Nothing in the picture moved.
- Then more of the game moved into entities: the local player and the camera, other players' avatars, the Boogler, the dino and the guest, and the HUD, pause, hotbar, prompt and conversation screens. Each now brings its own update and cleanup, like more toys arriving in their own boxes. An entity kind that keeps failing is now switched off only after 30 failures in a row, not at the first stumble. [One frame](#story/frame) still runs in the same order.
- The ball's game state can now run without a browser, so a test can roll it (and pass it between two pretend players) far faster than real time and check it lands where the browser's ball does, like a rehearsal without the stage.
- Last, only test tools: `?record=1` writes down your keys and buttons frame by frame, like a player piano roll, and a headless run plays that roll back on the newest build to name the first frame that differs. The jump's shape moved into the player's own state so both runs press the same code. Nothing shared changed, so nothing in the picture moved.
- A new prototype, a real place to find on foot and connect (`?proto=place`): a village, a gorge and two camps you link by rail. It reuses the rail loop's shared-world edits, so no arrow in the picture changes.
- Last, only small changes: trees and rocks are now written down as plain data (what each one bumps into and how much ground it takes), like a parts list kept apart from the paint job, so the game and a new level checker read the same list. Their new folder gets a note. Nothing in the picture moved.
- Then only small changes: the watering can left the item list (every room started fresh for it), and the code that hands a shared object like the ball from tab to tab now tells the object outright who holds it, like a relay baton that says whose hand it is in. [Kicking the ball](#story/ball) travels the same way, and nothing in the picture moved.
- Last, only controls and a prototype: one main button (RT or a left click) now uses what you hold or, empty-handed, bumps a nearby ball, so the separate bump and camera-zoom controls are gone, like a remote with fewer buttons. A new prototype (`?proto=onehand`) lets you hold just one thing, with no hotbar. Nothing shared changed, so nothing in the picture moved.
- Last of the day, only a prototype: the fall into the world (`?proto=fall`), where you roll a handcar off the end of a rail above the clouds and tumble into a big wooden BOOGLE sign whose letters you can kick around. It all happens in your tab only, like a cutscene nobody else needs to see, so nothing in the picture moved.
- Then, only Local changes about arriving and leaving: a first visit now starts with that fall, and a return puts you back where you last stood in that room, like a bookmark kept on your own device. The pause view gained Get unstuck (back to the spawn) and Start fresh (forget you on this device), and Leave now goes to a small menu page. Nothing is shared, so nothing in the picture moved.
- Then, only a prototype and a cleanup: the real place (`?proto=place`) gained a stations round, where you chop logs, feed them to track-laying machines, and pour rails at a forge to build a second line, like a model railway you build sleeper by sleeper. It all lives in your tab. The old code-posed hero is gone, since the Buddy replaced it. Nothing in the picture moved.
