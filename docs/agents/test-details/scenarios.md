# Choosing/running browser scenarios or GPU checks

- Browser scenarios (`dev/scenarios/`, `npm run scenario -- <name>`, `npm run look`; `.claude/skills/look/SKILL.md`) run on the owner's Mac, outside CI. `world-inputs` moved from software WebGPU CI into `dev/daily/jobs.ts` on 8 November; multiplayer scenarios also run daily there or explicitly with `check:gpu`. Failed runs retain images and Playwright traces (`npx playwright show-trace <zip>`) in their run folder. Commit scenarios, not ad-hoc Playwright scripts.
- The nightly run (03:30, [daily jobs](../../../dev/daily/README.md)) gives each scenario the machine bot slot before its 15-minute timeout starts and logs how long it queued and the load. Its worktree under `~/.boogle/daily/runs/` is locked: a cleanup must leave locked worktrees alone. A `runner:` line in the scenarios issue is tooling (the worktree vanished), not a scenario result. Results with a 1-minute load over about 30, or "WebGPU Device Lost" while other GPU jobs ran, are load until a quiet rerun says otherwise; that message also appears when a page closes after an earlier failure, so read the first FAIL.
- Scenarios with `island: true` open the current game, whose railway room refuses the classic lockstep edits (`gift.toss`, `src.take`, `site.stock`: server/test/railway-host.test.ts). A scenario that tosses, takes or stocks waits for an edit that never lands; one that needs a held edit sends the roster's `who.set`, which it takes (`reconnect-edit`). Since 9 November the live game hides the throw until replication R3 and `one-hand` and `interact` no longer toss ([decision](../../decisions.md), "Four more answers" (3)).
- A scenario that cannot pass in the current game but still needs a port sets `stale: '<why>'` (dev/scenarios/run.ts): every run prints it as `SKIP ... known stale`, runs the rest and never counts it as a pass; `--stale` runs it anyway. None is now (`hud-glance`, the last, was ported to the railway on 11 November). One whose subject left the game is deleted instead (`haul-loop`, `hut-build`).
