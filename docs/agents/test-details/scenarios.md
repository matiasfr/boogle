# Choosing/running browser scenarios or GPU checks

- Browser scenarios (`dev/scenarios/`, `npm run scenario -- <name>`, `npm run look`; `.claude/skills/look/SKILL.md`): PR CI runs single-player scenarios only (`world-inputs`; must pass): it can't run two rendering tabs reliably, and `SCENARIO_GATE=pr` makes the runner refuse a second one. Multiplayer scenarios run on a device (`check:gpu`, below) or nightly on the owner Mac (`dev/daily`, never block). Failed runs retain images and Playwright traces (`npx playwright show-trace <zip>`) in their run folder. Commit scenarios, not ad-hoc Playwright scripts.
