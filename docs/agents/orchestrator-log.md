## Process, 14 November

Every code change ships only after an independent review; docs-only changes ship with `--orchestrator-read`. Today's code batches above received independent Codex Astra reviews, two to five rounds. That does not settle the earlier after-the-fact reviews owed for the hall posts, Far Head's seated shot, seated Request stop/cab roof/vehicle spacing and catalogue ceilings; keep those with the owner. The rule was reaffirmed that morning after a slip: the orchestrator had shipped four code changes on its own read (#1771, #1782, #1783, #1784) before a permission check refused a fifth. #1771 (the hall's posts) was undone by #1778 on the owner's word; #1782 and #1783 were reviewed after the fact and one defect found (the seated bell), fixed in #1789; #1784 only removed test ceilings on the owner's call. Do not ship code with `--orchestrator-read`.

The repo-root main checkout is a detached launcher hundreds of commits behind `origin/main`. Agents work in their own worktrees from `origin/main`, never read plans from the launcher, and fetch and reset first when told to start from `origin/main`. For this docs-only snapshot, no fetch was run: the job forbids network access beyond its local server. Local refs and log were checked; active jobs, review rounds and live deployment were not independently polled.
