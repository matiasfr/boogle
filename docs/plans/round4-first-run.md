## Risks and checks

- Opening initialization races feature loading; configure before the director is imported and set active synchronously before place can place a body. Save readiness and player readiness are independent.
- `groundHeight` is wrong around world x≈1000. Replace all three opening ground assumptions, while keeping classic behavior.
- A restarting tab's `pagehide`, gift callback or late co-op snapshot must not recreate its removed save. Disable writes before deletion/navigation.
- An empty tab joining the same co-op room would immediately inherit the partner's railway. New room identity is required for a truly fresh run without resetting others; maintain that room in the destination URL across reloads.
- Do not change room wire formats, existing shared reset semantics or current gameplay copy. No lockstep or rendering-pipeline change is planned, so `check:full`/GPU performance runs are not required by scope; the broker captures exercise WebGPU health.
- Existing fall meshes/lights/tick work are reused; no new render budget system is being introduced.
