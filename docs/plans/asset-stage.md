# Asset and animation stage

## Goal and authority

Extend `/character/` into an isolated asset and animation inspector, with no island, room, physics, game features or game frame loop in that document. Serve **Understandable at a glance**, **Show, don't tell**, and **Small and readable** (DESIGN.md). Preserve existing character links and game behavior.

The owner explicitly approved and requested this build on 4 November 2026. Their task brief is the acceptance contract. The referenced research is absent in this checkout but was read at `../dev-tools-agentic/docs/research/dev-tools-agentic.md`, “A separate asset and animation stage” (33–49); `docs/research/material-pipeline.md` already links there. Its engine comparison favors an inspector like Unreal's animation editor/Unity's clip tooling/Godot AnimationPlayer, not another scene editor. No new research or network access is needed or authorized. Proceed within the approved scope; no new owner choice blocks implementation.

## Design

All stage state is **Local**, owned by this document: selection, camera, light preset, clock, playback, overlays and diagnostics. No sync API, messages, persistence, controls registry or room state. Native HTML inputs and OrbitControls provide mouse, keyboard and touch; no game action, pad slot or guide row is added.

### Catalogue and health

- Use `assets/built/manifest.json`, generated by `dev/assets/build.ts`, as catalogue membership. The four current entries are Buddy, hero-clips, place-kit and scaffold-kit. Names plus search satisfy version one; no thumbnail generation dependency.
- Add side-effect-free `character/descriptors.ts` for human names, Buddy's hero-clips relationship, expected clips, scaffold default node (`plank`) and root/socket semantics. Discover kit node choices from loaded glTF. No feature imports or second art source.
- Extract build manifest types/default budgets/hash/check facts into `dev/assets/manifest.ts`; let `build.ts` retain command execution. A small `dev/assets/vite-plugin.ts` supplies a virtual JSON catalogue/health module for dev and build. Compute actual source-plus-sidecar and output hashes using the existing 16-character SHA-256 convention; stale flags must be facts, not a browser guess from file modification times. Carry effective sidecar budget, current byte count, texture dimensions/formats and expected-clip failures. Omitted sidecars use current 1 MiB/asset and 12 MiB/total defaults.
- Import GLB URLs through Vite globs keyed by manifest entry; a missing output stays a visible disabled/error entry. Show invalid query values as a useful status and safely select a default.

### Shared runtime seams

- Extract the loader/conversion/instance/clip work from `src/render/assets.ts` into `src/render/asset-loader.ts`: `createAssetLoader(renderer, options)` owns Meshopt/KTX2, material conversion, per-instance cache and explicit disposal. Keep the game `loadAsset`, `loadAssetById` and `play` APIs and frame hook unchanged; that wrapper injects the game's renderer/boot timing. The stage imports the explicit core only. Material arrays remain supported.
- Extract body rig construction and animation from `src/player/buddy/body.ts` into a side-effect-free `src/player/buddy/rig.ts`. The game wrapper retains `startBuddy`, avatar installation, precompile and boot marks. The core receives the assets/avatar presentation data, `now`, `random`, charging state and paint callback explicitly; preserve constants, blending, stride timing, sockets, bounds and default random/clock behavior. Type-only avatar imports must not start the game.
- `makeLife` in `life.ts` accepts optional clock/random providers defaulting to today's `performance.now`/`Math.random`. Preview gets its own repeatable source and clock. Retarget math is unchanged; it is render-only, not lockstep.
- Prefer splitting `src/render/water/sky.ts` into an explicit renderer factory core (`sky-core.ts`) plus its existing game wrapper. Keep `createWaterSky`'s current game signature, constants and bake behavior unchanged. The stage can then reuse the real Hillaire atmosphere/cube without importing `scene.ts`, water state or game settings. Existing `Atmosphere` already takes the renderer when baking; `tone.ts` is side-effect-free. Bound this seam: if full cube reuse proves risky, share the shipped frozen lighting data/sample and explicitly label the missing environment/pipeline effects in the preset and report; do not widen into a water renderer redesign.
- Read nested `src/render/AGENTS.md` and `.claude/rules/state-consumers.md` before these edits; never add suppressions or a game loop door. No `src/sim`, world, networking or server changes.

### Stage presentation and animation

- Replace the monolithic `character/main.ts` with a small bootstrap using `character/catalogue.ts`, `character/preview.ts`, `character/buddy-preview.ts`, `character/lighting.ts`, and `character/inspect.ts` as needed. Avoid a framework: plain typed functions with explicit dispose/seek/update ownership.
- One WebGPU renderer, one scene and one linear HDR RenderPipeline in this standalone document. One-metre grid, contact floor, fixed scene lighting, orbit/pan/pinch and turntable. Fit camera to animated bounds while leaving room for a real idle Buddy at the side. Bounds and scale reference are independently toggleable; label dimensions in metres.
- Raw mode plays the selected authored clip through AnimationMixer; Buddy selects retargeted clips on the actual Buddy, with a clear label that “Raw” means retargeted clip without body blending/life (the source skeleton is inspectable through hero-clips). As played uses the actual shared rig update and life functions through `createBuddyPreview`, with explicit movement/airborne/carry/seated inputs. Do not copy the old viewer's approximate animation mixer logic and call it production playback.
- Give every available clip a name and duration. Large play/pause, loop, speed, scrub slider, numeric seconds, reset and ±1 frame controls use an explicitly labelled **30 Hz preview sampling** grid, not “native FPS.” Preserve exact numeric time including clip endpoints, where LoopRepeat must not wrap an end-pose seek to zero.
- `seek(t)` resets the preview state and repeatable random/clock, reconstructs the rig as needed, and replays 1/30 s steps plus the remainder to `t`; it must not merely change action time while procedural state keeps advancing. Seeking the same time twice must produce the same inspected transforms. Playback adds elapsed time without coupling turntable/camera to pose state.
- Wireframe uses cloned stage-owned materials; skeleton helpers and named socket axes attach to actual rig objects. Root trajectory samples authored root/pelvis tracks in asset space, and labels in-place/root semantics (hero-clips is explicitly supplied without root motion). Floor/scale Buddy/camera movement cannot create claimed authored root travel.
- Preserve legacy `clip`, `t`, `view`, `hat`, `pose`, `spin`, `hop`, `blink`, and `crowd` links where currently supported. The new canonical link serializes asset, node, clip, exact time, playback mode/pose, sampling FPS, light, camera position/target/FOV and overlay/view settings; copy-link has a selectable URL fallback. Keep named Front/Three/Side/Back/Close/Face/Game presets. `/assets/` can be a tiny redirect preserving query/hash, added to Vite's HTML inputs if straightforward.

### Lighting and measurements

- Studio preset uses neutral lighting and Neutral output. Shipped frozen-sky preset reuses the shipped sky factory at time .24, sun direction, irradiance fill and shared `agx`/exposure meter from `src/render/tone.ts`. Read `src/render/water/post.ts` for actual grade/exposure ordering. State excluded effects (sea/underwater/cave/world fog/bloom, if excluded) directly in the inspector; never call an approximate light colour “shipped sky.” Fix/reset exposure for reproducible paused views, stating that choice.
- Geometry stats distinguish selected asset from the full preview: triangles, vertices, material slots, unique geometries/textures, GLB bytes and clip count. Read actual renderer counters after a completed stage frame for measured scene draws; label inclusion of floor, reference, helpers, shadows and post passes. Do not call triangle-derived predictions draw counts.
- Estimate resident geometry buffers and unique texture allocation including mip levels, dimensions and actual compressed texture target format where available. Label **estimated GPU memory** and state exclusion of render targets/driver overhead; unavailable format/bytes remain unknown rather than zero. Show manifest/source/output hashes, budget and stale/missing-clip flags.
- Dispose replaced mixers, helpers, geometries/material clones, owned textures/cache and sky resources explicitly. Shared cached source resources remain alive until their loader owns disposal. Async selection uses a generation token so older loads cannot replace the latest choice.
- Defer two-version comparison: no version store or second build assets are provided, and implementing provenance/retention would widen this task. Say so in the report; reproducible links and Raw/As played are included.
