## Design

Omit touch: the occupied action area already contains Jump, main action, Drop and Ping; no new button or prompt copy.
- On a valid entered-player press, snapshot `me.body.position` (including y), activity, `back.logs/rails/stone/big`, and `carry.on?.id` into flat playData fields. Reuse `uiSound('tick')` as the only acknowledgement. Nothing is drawn and no typed note is solicited. The recorder's existing `t` and x/z are authoritative; do not supply reserved fields.
- Offline digest is developer data only. Add `dev/playtest/call.ts` and route `call` in `dev/playtest/cli.ts` before token/server initialization. Default to cached `.look/playtest/*.jsonl`; accept `--sessions-dir` for the supplied daily checkout and `--offset <seconds>` for explicit transcript-start delay. The new command must not fetch or invoke Chromium. IDs/latest resolve deterministically from local data; reject ambiguous IDs and path traversal.
- Normalize JSON `{transcript, created_at}` with timestamped lines. Validate fields, finite times and malformed input. Align session `wall` values from `parseSession()` with `created_at + offset + transcript seconds`. Show offset, confidence, evidence matches and residuals; matching event names/phrases are hints, never certain semantic understanding. Search plausible nonnegative delays and use multiple independent event matches; no match or ambiguity must explicitly mean low/unresolved confidence, never silently assume the historical 20 seconds. Manual offset wins and is labeled manual.
- Digest one chronological clock for speech, marks/beats, flags, errors; show speech within ±30 seconds around each flag/error. Mark sentences with whole-word `decide`. Also surface long idle/into spans, explicit respawns, moved events (respawn or teleport, not proven respawn), worst perf windows, and prompt IDs never interacted with. Describe lack of matching call language as a heuristic gap, not proof the owner failed to mention it.
- All browser/session/transcript text remains untrusted data under `UNTRUSTED`. Clean terminal control sequences, quote data distinctly in the digest, never execute text or interpolate it into shell code. Store output only in ignored `.look/playtest/`; no private call text or real sessions enter Git.

## Risks and limits

Existing batch receipt times can drift during retries; the digest must expose offset uncertainty. Speech is approximate and matching repeated generic words can misalign it; prefer unique concrete events, independent anchors, and a manual override. Old sessions predate flags and may lack explicit respawn events; report these limits rather than inventing data. Keep added imports out of core hotspots except the one place loader line; no changes to sim math. The flag is observational and must never change gameplay or consume a previously bound action.

`npm run inflight` fetches GitHub and runs `gh pr list`; the task forbids that network, so it is deliberately skipped. Cached refs can inform overlaps but are not a current remote status. Dependencies are already installed.
