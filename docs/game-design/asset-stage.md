# Asset and animation stage

`/character/` inspects built assets without an island, room, physics or game features. `/assets/` redirects here, retaining query parameters. All selection, camera, lighting and playback state is Local to this document. The catalogue is generated from the asset build manifest and side-effect-free descriptors; names and search list Buddy, hero-clips, place-kit and scaffold-kit. Kit meshes are individually selectable.

The viewport has mouse/touch orbit, pan and zoom, turntable, a one-metre grid, bounds/dimensions and an actual Buddy for scale. Wireframe, bones, named hand/back socket axes and authored local root/pelvis trajectory are optional. Hero-clips has no meshes and shows its skeleton. Root trajectory never includes camera motion; the character library is in place.

Every clip has a duration. Play/pause, loop, speed, scrub, numeric seconds, reset and frame-step controls use **30 Hz preview sampling**, not a claim about native glTF FPS. Exact endpoint seeks hold the final pose. Buddy Raw plays the real retargeted clip without body blending/life; the hero-clips entry shows the original skeleton. As played uses the same production body rig, retargeter and procedural life functions, driven by movement inputs chosen from the clip and the selected carry/hold/seated/airborne pose. Seek resets the clock, blink seed and state, then replays 30 Hz steps and any exact remainder. Playback advances the state without rebuilding it. This is a body preview, not a physics or game input replay.

Legacy clip/t/view/pose/hat/spin/crowd/blink links work. Legacy hop selects an airborne body pose at its supplied time; it is not a physical jump simulator. Copy this view records asset, part, clip, time, speed, loop, playback mode, pose, hat, camera position/target/FOV, turntable angle, light and overlays. For example: `/character/?asset=scaffold-kit&node=plank&clip=drop&t=0.1&view=Three`, or `/character/?asset=buddy&clip=Walk_Loop&mode=played&pose=carrying&t=0.4`. The selectable URL field is a fallback when clipboard access is unavailable.

Neutral studio uses linear HDR → Neutral → sRGB. Shipped frozen sky uses the actual atmosphere/cube, sun direction and sampled irradiance at .24, and the shipped AgX curve. Review exposure is adjustable and saved in the link; preset defaults are 1 for studio and .16 for shipped. It stays fixed for reproducibility: adaptive exposure, world fog, underwater effects and bloom are excluded and labelled. Both use the shared runtime loader/material conversion, including Meshopt and KTX2 support, and one standalone WebGPU renderer/pipeline.

The inspector counts triangles, vertices, material slots, unique geometry and texture dimensions/formats; hidden authored wear parts are included. Draw calls are measured from the completed stage render and include floor/reference/helpers, shadows and output. Estimated GPU bytes include geometry buffers and texture mip allocations (actual transcoded compressed mip byte lengths when available), exclude render targets/driver overhead and remain unknown when the texture allocation cannot be inferred. These are not device VRAM measurements.

The generated catalogue checks source-plus-sidecar/output hashes, actual output byte budgets and expected clips at serve/build time. Defaults remain 1 MiB per asset and 12 MiB total downloads; sidecar overrides apply. Rebuild/reload after editing assets. Replaced preview mixers, materials and helpers are disposed, and the document owns its loader/sky lifetime. Two-version comparison is deferred; this version offers reproducible single-view links and Raw/As played comparison.
