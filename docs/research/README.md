# Research

How to use this index: find your topic section, read the one line, then open a doc and read only its top block (verdict, top recommendations, status) unless you need the evidence; the body holds sources, numbers and method.

Status: **adopted** (built or decided as written), **partly adopted** (some taken, some turned down or still open), **open** (recommendations not yet acted on), **superseded** (replaced by the doc or decision named), **reference** (evidence, audit or history; nothing pending). Reports are dated evidence, not current contracts: [decisions.md](../decisions.md) and [direction.md](../direction.md) win.
