Bills and per-material distances were extracted from dev/loop/graph.ts (NODES, grindOf, carryMetres). Source distances average the nearest sources needed for the bill; depletion across stations is not simulated. Bill catalogs: line 1 and line 2. Each material uses separate trips (no mixed-load packing optimization), starts and ends at its receiving frame: empty outbound short route + loaded return, including a return to source on the first trip. Trips = ceil(bill/capacity). Heavy speed = 1 − 0.55 × excess/floor(comfort/2). Only a heavy loaded leg uses the long route.
