How to read the comparison

Blue is Quick boiler (25 m/s, current cars); green is Strong boiler (20 m/s, one extra car). Minutes include footing haul cycles plus sequential player travel legs. Savings are against 20 m/s with the current load. Shorter bars win. Both rows pay the same steel once; swaps are free.

Stand-in assignment: each area's footings are split equally across the lines it extends (rounded up); the full built line length at that stage is used. This is an editable scenario, not a designed freight itinerary. Other materials, source production, intermediate stops, walking, fares, contention and parallel travel are excluded. One effective service is modelled per line; actual fleet scheduling is unmeasured. Three players riding together fit in the same 4-seat car, so the default elapsed travel is the same at 1p and 3p, not divided by three. An editable handling allowance divided by player count exposes only off-train labour uncertainty.
